# 🔐 Cybersecurity Home Lab

## Overview

This repository documents my hands-on cybersecurity home lab and my journey developing practical skills in networking, Linux administration, security monitoring, attack simulation, detection, and incident investigation.

After earning my CompTIA Security+ certification, I created this lab to move beyond theoretical knowledge and gain practical experience with cybersecurity tools and concepts.

## 🖥️ Lab Environment

My virtual lab includes:

- VirtualBox
- pfSense
- Kali Linux
- Ubuntu Linux
- SIEM / log monitoring environment

The environment allows me to safely generate network and authentication activity, analyze logs, create detections, and practice security investigations.

## 📚 Lab Progress

### Phase 1 — Home Lab Setup
- Built a virtual cybersecurity environment
- Configured virtual machines
- Created an isolated lab network
- Configured pfSense as the lab gateway/firewall

### Phase 2 — Networking & Linux
- IP addressing and network interfaces
- Routing and gateways

### Phase 3 — Attack Simulation & Log Analysis
- Generated controlled SSH authentication attempts
- Simulated invalid-user and failed-password activity
- Analyzed Linux authentication logs

### Phase 4 — SIEM Monitoring & Investigation
- Collected and analyzed security events
- Created detection logic
- Investigated authentication activity
- Correlated multiple security events
- Analyzed sudo activity and privilege escalation
